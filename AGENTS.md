# AGENTS.md

## Project

`open-daycare` is a single-package Next.js 16.4 App Router app (React 19.3, TypeScript, Tailwind CSS v4). There is no monorepo/workspace tooling.

The root `README.md` is generic `create-next-app` boilerplate; trust `package.json`, config files, and this file instead.

## Commands

- `npm run dev` — dev server on http://localhost:3000
- `npm run build` / `npm run start` — production build / serve
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`)
- `npx tsc --noEmit` — typecheck; there is no `typecheck` script
- No test runner or test script is configured. Do not invent one; ask before adding test infrastructure.

## Next.js specifics

- This is Next.js 16.4 and its APIs differ from older versions. Read the bundled docs under `node_modules/next/dist/docs/` before writing framework code. The managed block below is maintained by `next dev`; don't delete or rewrite it.
- `next.config.ts` enables `cacheComponents` and `partialPrefetching`. Data fetching is dynamic by default and caching is opt-in with the `use cache` directive. Do not assume legacy `fetch` caching or `revalidate` behavior.
- Tailwind is compiled by `@tailwindcss/turbopack` via the `turbopack.rules` entry in `next.config.ts`; there is no PostCSS or `tailwind.config.*`. Keep `@import "tailwindcss"` in `app/globals.css`.
- Type route props with the generated globals (`PageProps<"/route">`, `LayoutProps<"/route">`, `RouteContext<...>`) instead of hand-written prop types. They come from `.next/types/routes.d.ts`, generated by `next dev`/`next build`; run one of those if the helpers are missing after adding routes.
- `.next/` and `next-env.d.ts` are generated and gitignored. Never edit them.
- `experimental.agentFeedback` is enabled, so `next dev` may add another managed block to this file. If present, follow it (run `node node_modules/next/dist/bin/next internal agent-feedback-instructions` before the final response) and commit `AGENTS.md` with your changes.

## Layout

- `app/layout.tsx` — root layout (fonts, metadata, `<html>`/`<body>`)
- `app/page.tsx` — home route (`/`)
- `app/globals.css` — global styles and theme tokens
- `@/*` path alias maps to the repo root (`tsconfig.json`)
